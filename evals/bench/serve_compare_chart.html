Time per task

Minutes of wall-clock time for a full harness turn, thinking, tool calls and checks included. Bars are the mean of each task's repeats (coding tasks ran 3 times, ARC puzzles once); dots are the individual runs. A red ✕ is a wrong answer.

Why a faster decoder is not always faster

Same runs, three views. The fast server reads tokens out fastest, but it writes more of them per task than the recommended one, so the two end up level on time. The precision server's average is pulled up by one ARC puzzle that ran into the 20-minute limit.

Numbers behind the charts

Every server ran with 80,000 tokens of context, two slots, the same harness code, Jev, personas and sampling; only the GPU was the 3090. Each run's hidden tests (coding) or exact-match grid (ARC) decide right or wrong.
